# Lilo's fart sound

`rigid_fart.wav` is "Rigid Fart" from SoundBible.com: https://soundbible.com/680-Rigid-Fart.html

Licence: Creative Commons Attribution 3.0 (https://creativecommons.org/licenses/by/3.0/). It is free to use, in games too, as long as the sound is credited. Credit: "Rigid Fart" by SoundBible.com.

What was changed: silence trimmed from both ends, a short fade in and out, loudness evened out to sit with Lilo's mews, and converted to 16-bit mono 16 kHz. `scripts/make_lilo_sounds.py` turns it into `kFart` in `shared/lilo_sounds.h`.

The file was taken from the `ovos-skill-fart` package on PyPI (`sounds/fart-09.mp3`), whose `ATTRIBUTION.md` names it as SoundBible's "Rigid Fart" (original file `Rigid Fart-SoundBible.com-1121832279.mp3`).
