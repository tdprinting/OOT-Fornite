# Code map

One line per hand-written file or folder. Mod features: [`mod/Royale/FEATURES.md`](../mod/Royale/FEATURES.md). Docs: [`README.md`](README.md).
`[gen: X]` = generated by X; never edit, regenerate. Generated arrays are hidden by `.rgignore` and denied to Read in `.claude/settings.json`.

## shared/ (game-independent C++, used by server, client, mod and tests)
- Protocol and net: `protocol.h` wire format (versioned, `kProtocolVersion`); `bytes.h` bounds-checked LE serialisation; `transport.h` network interface; `loopback.h` in-memory network for tests; `enet_transport.h`/`.cpp` real UDP.
- Rules: `balance.h` all tunables; `combat.h` per-item damage; `items.h` item catalog; `loot.h` chest spots and loot; `storm.h` storm circles from (seed, map, time); `rng.h` splitmix64; `controls.h` pad layouts; `names.h` bot names; `replay.h` end-of-match replay.
- Maps: `map.h` map list and ids (default Moonfall Isle, id 12); `terrain.h` floor height; `placement.h` where things go; `poi.h` towns and places; `props.h` scattered scenery; `island_anchors.h` chest anchors on the Fortnite Map; `fortnite_map.h`, `fortnite_scenery.h`, `fortnite_puddles.h` Fortnite Map; `sandbox_terrain.h`, `sandbox_layout.h` Sandbox; `boss_arena.h` boss test arenas; `convergence_layout.h`, `kingdom_layout.h`, `moonfall_layout.h`, `riftlands_layout.h`, `skyloft_layout.h` authored islands (read their `_data.h`).
- World look: `weather.h` seasons and weather; `ground_patches.h` puddles, snow, leaves; `water_sim.h`, `water_look.h` water physics and look; `meshes.h` code-built low-poly models; `objmodel.h` OBJ loader; `dynamic_shadows.h` light/shadow maths; `graphics_layers.h` layer bookkeeping; `graphics_stability.h` camera-relative vertices; `frame_cache.h` fixed cache; `asset_relief.h` relief from loaded textures; `gilded_sword_surface.h` sword normal/bump maps; `engine_limits.h` raised engine limits (patch 0029).
- Actors: `anim.h` coarse anim state on the wire; `boss.h` bosses; `bokoblin.h` Bokoblin helpers; `bokoblin_anim.h`, `ally_anim.h`, `avriella_anim.h`, `lilo_anim.h`, `maya_anim.h`, `jones_animation.h`, `chief_animation.h` pose/skinning; `link_anims.h` our Link jump/land/sprint joint-table clips [gen: tools/link_anims/build_link_anims.py, rig = player's local Adult Link export, never committed]; `ally.h` hireable allies; `vehicle.h` Lon Lon Buggy; `skins.h` tunic skins and the skin model name list; `skin_model_types.h` skin model layout, `skin_<id>_model.h` skin models [gen: tools/skins/export_skin.py]; `cloth.h` hat/glider cloth; `tail_swing.h` pet hair; `tablet_physics.h` Maya's tablet; `lobby_fish.h`, `lobby_reef_geometry.h` lobby aquarium; `lobby_pets.h` pet group events.

## server/ (host simulation; header-only, built by `server/CMakeLists.txt`)
- `sim.h` match plus bots, `Tick(dt)` entry point.
- `match.h` `class Match`: players, loot, storm, bosses, allies, carts.
- `boss_helpers.inc` Bokoblin helper members, included inside `Match`.
- `bot.h` bot brain (movement, looting, combat, carts).
- `nav.h` walkability grid for bot paths.
- `game_server.h` host server: owns the match and bots, talks through a `Transport`.
- `tests/` one `*_tests.cpp` per system (`tests.cpp` is the big core suite; `net_tests.cpp` loopback, `enet_tests.cpp` real UDP, `session_tests.cpp` `RoyaleSession`).
- `tools/balance_sim.cpp` headless bot-only balance runs; `tools/performance_bench.cpp` nav/sim timing; `tools/placement_preview.cpp` dumps a map layout (draw with `tools/maps/placement_preview.py`).

## client/
- `game_client.h` client state, interpolation and events for the game layer (HUD, sound, effects).

## mod/Royale/ (game-facing; one translation unit `RoyaleMod.cpp`, features in `features/*.inc`)
- `RoyaleSession.h` host/join layer without game code (transports, host server).
- `RoyaleBosses.h` boss state + shared draw helpers, then includes `bosses/`: `MiniBosses.inc` (with `RoyaleChuChu.h`), `Volvagia.inc` (dragon + custom model), `MajorBosses.inc` (Morpha, Phantom Ganon, Bongo, Twinrova), `BossActor.inc` (stand-in actor, reconcile, HP bars), `StrikeFx.inc` (strike warnings/blasts, body fx).
- `RoyaleBokoblins.h` Bokoblin helpers (from `WorldObjects.inc`); `RoyaleJones.h` Jones NPC, `RoyaleChief.h` Master Chief NPC (from `Companions.inc`).
- `RoyaleLobbyFish.h` lobby aquarium; `RoyaleLobbyPets.h` lobby pet play.
- `RoyaleWarTable.h` native menu; its fragments in `war_table/` (index: [`war_table/INDEX.md`](../mod/Royale/war_table/INDEX.md)).
- `build_version.h` build number, overwritten by `game-build.yml`.
- `features/CrashContext.inc` crash context: state snapshot and change breadcrumbs printed into `royale-crash.txt` and each scene load's block in `royale-trace.txt` (see `docs/BUILDING.md`).
- `features/AutoTest.inc` playtest step-script driver (`ROYALE_AUTOTEST`; inert otherwise), used by `tools/playtest/`.
- `logo_data.h` [gen: scripts/make_logo_assets.py]; `gilded_sword_icon.h` [gen: scripts/make_gilded_sword_icon.py].

## scripts/
- Build: `apply_patches.sh` applies `patches/` to the fork; `link_mod.sh` copies the mod into the fork; `apply_logo.sh` icons; `royale-debug.keystore` debug signing key.
- Checks: `check_mod_layout.py` feature packaging (`--baseline` proves byte-identical TU); `check_mod_compile.sh` compiles `RoyaleMod.cpp` against the fork; `check_surface_patch_stack.py` engine patch stack; `mod_source.py` expands the TU for checks.
- Tests run by CI (`ci.yml`): `test_water_draw_buffers.py`, `test_item_surface_maps.py`, `test_item_surface_shaders.py`, `test_kingdom_authoring.py`, `test_moonfall_authoring.py`, `test_skyloft_authoring.py`, `test_riftlands_integration.py`. `game-build.yml`: `test_surface_renderer_state.py`. Manual: `test_war_table_matrix.py`, `test_playtest_equipment.py` (Windows).
- Generators (`make_*.py`): each writes the header named in its docstring (see generated lists above).
- `github_brief.py` bounded PR/run summaries.

- `maps/kingdom/`, `maps/moonfall/`, `maps/riftlands/`, `maps/skyloft/` (`textures.py` adds the isle's own textures): authored islands (`layout.py` places, `pois.py`/`props.py` buildings, `terrain.py` ground, `world.py` assembles, `export.py` writes `shared/*_data.h`/`_model.h`, `blender_build.py` .blend, `routes.py`/`author_nav.py` bot floors, `validate.py`/`scale_audit.py` checks). `riftlands/gallery.py`, `prop_sheet.py`, `maps/preview_lighting.py`: manual Blender QA.

- `build_war_table_assets.py` menu art tiles; `check_war_table_windows.py` local Windows syntax check; `patch_war_table_engine.py` one-off author of patch 0025a (already landed).
- `song-to-oot.html`, `song_to_oot/` song converter (browser and Python); `rom-extractor.html` ROM collision analyser; `map-viewer.html` map viewer; `test_rom_extractor.js`, `test_song_to_oot_html.js` manual `node` tests.

- `playtest/`: headless playtests of the real PC build (`build.sh`, `run.py` scenarios and suites, `sync_mod.py` incremental mod copy); docs/PLAYTEST.md.
